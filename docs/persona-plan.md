# 人设“真（シン）”：萌芽阶段的决定与待办

2026-11-05 起。站长想像 Innei 的 [人设页](https://innei.in/settei) 那样，有一个自己创造的动漫人物，承载“灵魂的本色”。现在只是萌芽，不急着上线。

## 已定

- **名字：真（シン）。** 和 Sin 同音，意思是“求真”。站长喜欢《仙逆》的王林和《求魔》的苏铭，两人走的都是求真之路。
- **一个人物，两层颜色。** 不做两个角色。
  - 灵魂底色是紫：取自站长自己写的一言“那紫色在白天里不如夜的黑，可是在黑夜中，是那黑夜也无法渲染的暗”。她还在路上，有点倔，手里有本记满新学到的词的小本子（对应碎碎念里收集事物名字的习惯）。
  - 对美化的向往是月光：站里强调字用的暖奶白（`--moonlight`）。是她走向的方向，也是她能飞起来时的样子（对应凌晨四点想在梦里飞起来的那个梦）。
- **必须原创。** 不能像丛雨或 Innei 的汐音（银白头发、淡粉、樱花那一套）。辨识度放在紫色和夜晚。

## 待办

1. 写文字设定：名字、资料（生日 5 月 3 日）、性格关键词、一句台词、配色（直接取 `apps/web/app/globals.css` 的色值）、一两个标志物。
2. 用 AI 出几版草图挑方向（一张图，紫色加月光）。
3. **首页“影子”**：首屏头像背后放她的形象。月亮在右上，影子落在左下：紫色剪影 + 一圈淡月光边，平时淡、悬停变清晰。
4. **人设页**：先在后台“页面”里新建（会自动出现在导航“首页”面板，和“关于我”“关于本站”并列），富文本写设定和图片；以后要做三视图、色卡、表情格子那种排版，再给这一页加专门版式，内容仍在后台。
5. **用“真”替换首屏的丛雨**（站长 2026-11-05 确认要做）。丛雨是柚子社角色、首屏那张是同人图，只能个人非商用，不能当站长的 IP；同一屏放两个动漫人物也会抢戏。替换时注意：丛雨的对位按 “Sin” 三个字母调的（`apps/web/components/home-hero.css`、`home-hero.tsx` 的 MascotLayer、`apps/web/public/mascot/`、e2e `scripts/e2e/hero-mascot.mjs`），要一起改掉。
6. 如果以后真拿她做长期 IP：找画师按设定正式重画，约稿写明买断或完整商用授权。
