# 用 iPhone 快捷指令一键收录一言

朋友说出金句时，在微信里长按复制，点一下快捷指令，填上是谁说的，就直接存进一言，不用打开后台。快捷指令调用的是 Core 自带的“新建一言”接口（`POST /says`），Core 不用改；存进去以后 Core 发 `SAY_CREATE` Webhook，前台一言页的缓存马上失效。

## 一、在后台建一个令牌

后台“设置 → 账户 → API Token → 管理 API Token”，新建一个，名字写“iPhone 收录一言”，复制生成的令牌。

注意：Mix Space 的 API Token 权限和登录后台一样大，只放在自己手机的快捷指令里，不要发给别人；手机丢了就在同一个页面把它删掉。

## 二、在“快捷指令” App 里新建

新建快捷指令，名字叫“收录金句”，依次添加这些动作：

1. **获取剪贴板**
2. **要求输入**：提示写“谁说的？”，输入类型选“文本”
3. **要求输入**：提示写“出处（可以不填）”，比如“与捞大的微信聊天”
4. **获取 URL 的内容**：
   - URL：`https://<线上 Core 地址>/says`
   - 方法：POST
   - 头部：`x-api-key` 填第一步复制的令牌
   - 请求体：JSON，三个字段，都是文本：
     - `text` → 选第 1 步的“剪贴板”
     - `author` → 选第 2 步的“提供的输入”
     - `source` → 选第 3 步的“提供的输入”
5. **显示通知**：写“收好了”

本地开发时手机连不到电脑上的 `127.0.0.1`，要测试的话把 URL 换成电脑的局域网地址（手机和电脑在同一个 Wi-Fi，Core 也要允许局域网访问）；平时用线上地址即可。

## 三、平时怎么用

在微信里长按那句话，点“复制”，再运行“收录金句”。可以把它加到主屏幕，或者在“设置 → 辅助功能 → 触控 → 轻点背面”里设成“轻点两下”，复制完敲两下手机背面就能收录。

收录后打开一言页就能看到（按人看、抽一句、做成卡片都会带上这一条）。写错了在后台“一言”里改。
